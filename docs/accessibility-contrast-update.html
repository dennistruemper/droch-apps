22 November 2026 · Follow-up to the initial axe audit.

All 69 scans completed with zero color-contrast violations. Removing static text fading resolved every confirmed contrast finding in the audited states. Other accessibility findings remain: 32 affected scans and 6 rule IDs. Counts include repeated screens/profiles, not separate underlying defects.

What changed

Shared small text, section headings, citations, placeholders and disabled labels use full opacity. App-specific text fading was removed from Kunludo, Poker and SchleZaZ. Existing type sizes preserve hierarchy; Kunludo’s secondary readiness count uses regular weight, placeholders use italics and disabled controls use dashed borders. The vendored Drochsign source was preserved; shared changes live in its integration stylesheet.

Remaining fixes

These markup changes are proposed next steps and have not been applied in this typography change.

Issue Fix
Vortoj score and tile button names Let the visible wording form the accessible name, preserving its wording/order and spacing. Use aria-labelledby for visible text where needed and aria-describedby for extra context. For score controls, include “Your score” and its value; keep the explanation of players/game details in a description. Include both the visible letter and points in tile names.
Duplicate desktop page banners Replace the shared menu’s header[data-panel-heading] with a neutral container, preserving its CSS hook and layout. Keep the actual page header as the banner. This resolves two related axe rules without merely renaming duplicate banners.
Kunludo account landmarks Use main for the standalone account screen’s primary content. The signed-in planner already has its own main, so avoid nested main elements.
Kunludo mobile headings Put one visible page-purpose h1 in the main content, reflecting the selected view, such as “Spiele” or “Teams”. Keep it available when the mobile menu is closed; avoid repeating identity or adding a slogan.
